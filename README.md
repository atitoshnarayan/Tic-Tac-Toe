# Tic-Tac-Toe vs Unbeatable Computer

A terminal Tic-Tac-Toe game in Python. You play X against a computer
that uses the minimax algorithm, so it never loses.

## How to run

- Play: python tictactoe.py
- Test: python test_tictactoe.py

The test plays all 681 possible games where the human moves first.
Result: the human wins 0, the computer wins 498, and 183 are draws.
